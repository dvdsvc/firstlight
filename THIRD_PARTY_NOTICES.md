# Third-party components and research attribution

The repository depends on the OpenAI Python client, MCP Python SDK, python-docx, openpyxl, python-dotenv, NumPy and SciPy; packaging uses uv and setuptools. Their implementations are not vendored and retain their own license terms. The repository lock is a new presentation-environment resolution.

The original `vocab.py` identifies its vocabulary/constraint basis as copied from the adjacent `geochron_pipeline_v3` project. Profile field cards retain a USGS template source reference in their original code. Those references do not establish sole authorship or standards certification. Component authorship, collaborator attribution and the project distribution license remain for owner confirmation; see [provenance](docs/provenance.md).
