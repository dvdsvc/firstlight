# 科学文献实体树抽取与校验：研究介绍

[项目入口](../README.zh-CN.md) · [完整方法](methods.md) · [版本关系](versions.md) · [历史证据](evidence.md)

## 简历短版

围绕地质年代学文献中的样品—测点—年龄—误差关系，实现实体树驱动的分阶段抽取流程：R1 发现结构，R2a 补充样品属性，R2b 读取测点数值，R2c 映射受控词表；通过字段限制保留关键数值，并导出带论文／样品关联的 JSON 与研究表。进一步探索基于已知答案控制的遗漏／错绑诊断，以及以前期抽取关系为种子的文档图候选恢复。个人贡献范围需作者最终确认。

## 个人主页版

本项目研究科学文档中的结构化信息如何在多阶段处理中保持关系一致性。以年代学文献为场景，系统先建立样品、测点和年龄事件的实体树，再将属性补充、数值读取和术语规范化分配给不同阶段，并用确定性规则限制结果合并。输出采用关联表组织，便于后续地质数据分析。在主流程之外，还保留了状态式抽取 Agent、MCP 工具接口、带已知答案的控制文本，以及种子驱动文档图补全实验，分别检验结构写入、遗漏诊断与候选恢复机制。

## 详细研究介绍

研究起点是科学信息抽取中的关系归属：抽到一个年龄数字，并不等于得到可使用的地质记录；还需要知道它属于哪篇论文、哪个样品、哪种分析及何种误差语义。主流程用显式实体树表达这些关系，并把“发现实体与事件”“填写属性”“读取表格测点”“规范化专业术语”分开处理。R1 的多温度采样、R2a/R2c 的样品批处理和并发调度都在源代码中有对应实现。

受限合并是一个具体的技术重点。R2a 只改指定样品属性；R2b 保留允许的测点字段；R2c 以 R1 事件为基础，保留原先的年龄数值与误差大小，再补充统计描述和专业术语。这体现了利用程序约束模型输出的思路，而不是把所有轮次的完整 JSON 直接互相覆盖。当前约束仍有明确边界，例如事件按列表位置对齐，词表主要由提示词提供，而非主 API 的严格 Schema 校验。

工程与研究实现还包括两类出口：单篇 JSON／审核表，以及跨论文的关联表。后者以 paper_id 和 sample_id 共同维持归属，连接 reference、samples、observations 和 measure_events。导出层有明确筛选和去重语义，因此需要区分内部抽取结果与供分析使用的投影；整理版以虚构的跨论文同名样品检查验证这条关系。

后续 Agent 实验把阶段边界进一步表达为 profile 局部状态和增量写入权限。已知答案控制文本用于观察漏项、合并、错绑或来源混淆，并在写入真实状态前剔除控制数据。另一组独立图实验以前期抽取的样品／数值／误差关系作为锚点，通过结构路径、最短路定位和最小 Dirichlet 能量传播提出候选关系。这两组研究保留在同一仓库，但尚未形成自动图恢复写回与主导出贯通的完整链路。

历史批量目录中保留 310 份最终 JSON，内有 1,752 条样品、9,789 条测点和 6,140 条事件记录。这证明有真实的批量执行与数据组织工作；它不是金标准评测，不能改写为准确率或已验证的算法收益。对导师展示时，重点可以放在科学问题拆解、结构表示、模型任务设计、约束实现、运行与输出审计，以及对研究边界的把握。
